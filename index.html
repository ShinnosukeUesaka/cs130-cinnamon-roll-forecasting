How to read this

Increase model flexibility from degree 1 to 15. The training error cannot rise here because each higher-degree model includes all the lower-degree curves. Test error often falls at first, then rises when the fit starts following random fluctuations. Its exact minimum can move when you change the sample.

These are invented numbers for a teaching example, not sales data from Zeit für Brot. The test set contains 1,000 independently simulated observations. The same test set is used for every degree in a run. No model is selected using that test set in the simulation.
